# AppLovinMediationIronSourceAdapter

AdsEye 维护的 Swift Package，来源版本 `9.4.0.0.0`。

在 Xcode 中添加 [本仓库](https://github.com/AdsEye/AdsEyeSPM-AppLovinMediationIronSourceAdapter)，选择 Exact Version `9.4.0-pod.0.0`，并将 `AppLovinMediationIronSourceAdapter` 添加到 App target。部署目标为 iOS 13 及以上。

App target 的 `Other Linker Flags` 加上 `$(inherited) -ObjC`。
